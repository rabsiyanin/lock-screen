# ScreenLock — кнопка блокировки экрана для Android 9+

Значок приложения и виджет 1×1: одно нажатие — экран заблокирован.
Работает через службу специальных возможностей (как кнопка питания), поэтому
отпечаток и разблокировка по лицу продолжают работать. Служба не подписана
на события и не читает содержимое экрана. Сторонних библиотек нет.

## Файлы
- `app/src/main/java/.../LockService.kt`  — служба, выполняет «заблокировать экран»
- `app/src/main/java/.../LockActivity.kt` — невидимая activity (значок / цель виджета)
- `app/src/main/java/.../LockWidget.kt`   — виджет 1×1
- `app/src/main/res/xml/accessibility_service_config.xml` — конфигурация службы
- `app/debug.keystore` — ключ подписи (пароль `android`), чтобы сборки с разных машин ставились поверх друг друга

## Как собрать APK

### Вариант 1. Android Studio
1. Установите Android Studio, откройте папку проекта (File → Open).
2. Дождитесь окончания синхронизации Gradle (первый раз скачает SDK, несколько минут).
3. Build → Build App Bundle(s) / APK(s) → Build APK(s).
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
   Либо подключите телефон по USB с отладкой и нажмите Run ▶ — установится сразу.

### Вариант 2. GitHub Actions (ничего не устанавливая)
1. Создайте репозиторий на GitHub (можно приватный) и загрузите в него содержимое проекта,
   включая папку `.github`.
2. Откройте вкладку Actions → «Build APK» → дождитесь зелёной галочки.
3. Внизу страницы запуска в разделе Artifacts скачайте `ScreenLock-apk` (zip с `app-debug.apk`).

### Вариант 3. Командная строка
Нужны JDK 17 и Android SDK (cmdline-tools), переменная `ANDROID_HOME`, принятые лицензии
(`sdkmanager --licenses`). Затем: `./gradlew assembleDebug`.

## Установка и включение
1. Скопируйте APK на телефон и откройте его (разрешите установку из этого источника).
2. Настройки → Специальные возможности → Скачанные приложения → «Блокировка экрана» → включить.
   На Android 13+ переключатель для установленных вручную приложений заблокирован
   («Настройка с ограниченным доступом»). Тогда: Настройки → Приложения → Блокировка →
   меню ⋮ вверху справа → «Разрешить ограниченные настройки», после чего включите службу.
   Установка через `adb install` обходит это ограничение.
3. Добавьте виджет «Блокировка» на рабочий стол (долгое нажатие по столу → Виджеты)
   или просто вынесите значок приложения.
